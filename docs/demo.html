Install BliForest sebagai PWA

BliForest dapat dipasang langsung dari browser dan digunakan seperti aplikasi.

Android / Chrome

  1. Buka BliForest melalui Chrome.
  2. Tekan menu ⋮ di pojok kanan atas.
  3. Pilih Install app atau Tambahkan ke layar utama.
  4. Tekan Install.

Desktop / Laptop

  1. Buka BliForest melalui Chrome atau Microsoft Edge.
  2. Klik ikon Install pada bagian kanan address bar.
  3. Klik Install.
Setelah terpasang, BliForest dapat dibuka dari layar utama atau daftar aplikasi. Untuk penggunaan offline, buka aplikasi setidaknya sekali saat masih terhubung internet agar file PWA tersimpan di perangkat.
